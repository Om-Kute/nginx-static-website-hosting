# DevOps Engineer Portfolio Website 🚀

This is a modern and responsive DevOps portfolio website hosted on AWS EC2 using Nginx.
Its is simple ways to host our first understanding website hosting
## Technologies Used

- HTML5
- CSS3
- JavaScript
- AWS EC2
- Ubuntu Linux
- Nginx
- Git & GitHub

## Features

- Responsive Design
- Animated UI
- Interactive Sections
- Modern DevOps Theme
- Smooth Scrolling
- Glassmorphism Effects

## Deployment Steps

1. Launch AWS EC2 Instance
2. Install Nginx
3. Copy project files to:
   /var/www/html
4. Restart Nginx
5. Access using Public IP

## Commands Used

```bash
sudo apt update
sudo apt install nginx -y
sudo systemctl start nginx
sudo systemctl enable nginx
